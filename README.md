# Solo Travel Planner 🌏

A full-stack web application for planning solo trips in Vietnam.

## Tech Stack
- **Frontend:** ReactJS, Vite, TailwindCSS, React Router DOM
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Auth:** JWT, bcryptjs
- **Deploy:** Vercel (frontend), Render (backend)

## Features
- JWT Authentication (Register/Login)
- Browse & search travel destinations
- Filter by category
- Create & manage trip plans
- Admin dashboard (manage destinations & users)
- Responsive design
